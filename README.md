# 律所 GEO 优化平台 · AI 产品经理作品集

单文件作品集主页 + 可点击 Demo（静态演示模式）。

## 页面

- **作品集主页**：`index.html` —— 项目概览、设计文档、可审阅 PRD、综合方案图、评测方案
- **可点击 Demo**：`demo/index.html` —— 8 模块 GEO 运营平台，144 条真实数据快照，写操作存于浏览器 localStorage

## 部署

推送到 `main` 分支后，GitHub Actions 自动部署到 GitHub Pages。

本地预览：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

## 数据说明

Demo 为静态演示版：数据快照取自原云端 Demo 的真实导出记录，不含真实客户隐私信息；AI 生成为本地示例输出，不调用真实模型。业务指标均为仿真数据，不代表生产环境效果。

## 证据分级

- `[真实]`：有数据或运行记录支撑
- `[仿真]`：在自建样例集上跑出的结果
- `[估算]`：基于行业基准推算
- `[假设]`：尚未验证的目标

对外页面只含可公开展示的内容；内部备战材料未上传本仓库。
